# NAMMA-KADA

## Voice-First Digital Khata for Small Businesses

NAMMA-KADA is a Python-based application designed to help small business owners manage customer credit and transactions through a simple and voice-friendly interface.

## Features
- Customer credit management
- Transaction tracking
- Voice-based interaction
- Easy-to-use interface

## Technologies Used
- Python
- Streamlit
- AI/ML
- Firebase (Planned)

## Project Files
- `app.py` - Main application file
- `voice_test.py` - Voice testing module

## Future Improvements
- WhatsApp integration
- Multi-language support
- Automated reminders
